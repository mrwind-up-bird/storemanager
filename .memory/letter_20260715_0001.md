### Key facts learned (also in nyxCore)
* **`qr_owner` has BYPASSRLS** (`docker/postgres/init/01-roles.sql:13`). RLS is **NOT** a backstop for ownerPool writes/deletes — the ONLY tenant scope on that path is the explicit `WHERE tenant_id`. The RLS-enforced path is `withTenant` (appPool / `qr_app`).
* **Destructive per-tenant wipe order** (FK `ON DELETE no action`): `wishlist_matches → transaction_items → transactions → record_embeddings → purchases → records`.
* **v1 schema shape** (from the dump): `records`(artist = plain string; `format` = media/beverage discriminator; `record_status` enum '10'..'80', default '20'; `sold` bool; `hash`), `purchases`(purchase_price/target_price/sold_price/sold_date/payment_method, **NO condition**), `conditions`(separate table: record_id/purchase_id → condition_cover/record int), beverages + Quick-POS live in `transactions`/`transaction_items` **NOT** in `records`. v2 `hash` = `recordHash` (sha256 of `artist|title|country|year|label`, trim+lowercase).
